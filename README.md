# 🤖 IoT Sensor Projects using Raspberry Pi

This repository contains mini-projects that demonstrate how to interface **IR**, **LDR**, and **Ultrasonic sensors** with a **Raspberry Pi** for Internet of Things (IoT) applications. Each project includes circuit diagrams and Python code to help beginners get started.

---

## 🧠 Project Highlights

| Sensor Type | Functionality | Images/Code Included |
|-------------|----------------|-----------------------|
| **IR Sensor** | Detects object presence | ✅ Circuit Diagrams, ✅ Python Code |
| **LDR Sensor** | Detects light intensity | ✅ Circuit Diagrams, ✅ Python Code |
| **Ultrasonic Sensor** | Measures distance | ✅ Circuit Diagrams, ✅ Python Code |

---


## 🔌 Hardware Requirements

- Raspberry Pi (any model with GPIO)
- Breadboard and Jumper wires
- IR Sensor
- LDR (Photoresistor)
- Ultrasonic Sensor (HC-SR04)
- Resistors (as per circuit)
- Power supply

---

## 🖥️ Software Requirements

- Python 3
- RPi.GPIO or GPIO Zero library
- Raspberry Pi OS Lite

---

## 🚀 How to Run

1. Connect each sensor using the respective circuit diagrams provided.
2. Open the corresponding Python code.
3. Run the script:
   ```bash
   python3 <sensor_code.py>
